Setup. The Rubingh framework requires one pair (x₁, β) to satisfy both component equations at once:

PE65 (comp. 1): β = ln(α₁·C_mix / (x₁·C₁)) / (1−x₁)²

with α₁ = 0.4, C₁ = 33, C₂ = 330, C_mix = 116 (all mg/L). These equations depend only on CMC ratios, so the mass-based values can be used directly.

The two equations never agree. Writing β₁(x₁) from the PE65 equation and β₂(x₁) from the oleate equation:

β₁(x₁) is positive for all x₁ ∈ (0,1), because the argument α₁·C_mix/C₁ = 46.4/33 = 1.41 > 1.
β₂(x₁) only becomes positive when 1−x₁ < 0.211, i.e. x₁ > 0.789 (argument α₂·C_mix/C₂ = 69.6/330 = 0.211).

In the only region where both are positive (x₁ > 0.789), β₁ runs from ~13 upward while β₂ stays near 0–3, and β₁ > β₂ everywhere up to x₁ → 1. The curves never cross, so no self-consistent root exists. The solver confirms this: status: no_solution for exactly these inputs.
