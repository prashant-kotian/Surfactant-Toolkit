To detect the scale-corrupted row, we evaluate all possible 2-segment OLS fits (with $\ge 3$ points per side) on the raw 9-point data and find the split that minimizes the Residual Sum of Squares (RSS). Then, we perform a leave-one-out cross-validation to see if removing a single point reduces the total minimum RSS by more than half. 

### 1. Identify the corrupt row (Leave-one-out RSS)
For the raw 9 points, there are 4 possible splits (3 left/6 right, 4L/5R, 5L/4R, 6L/3R). The RSS-minimizing split for the raw data is **4 left, 5 right**, yielding:
- `RSS_before` = 899.50745

We run the same procedure for all 8-point subsets formed by dropping one point. Removing row 4 (where $\gamma$ = 0.046 mN/m) gives a new RSS-minimizing split of **5 left, 3 right** on the remaining points:
- Left 5 points ($c$: 0.20, 0.50, 0.90, 2.40, 3.60): RSS = 0.31943
- Right 3 points ($c$: 5.20, 7.20, 10.00): RSS = 0.05556
- `RSS_after` = 0.37498

Since 0.37498 is vastly less than half of 899.50745, row 4 is successfully flagged as a corrupt outlier. Its concentration exactly as printed is **1.50**.

### 2. BIC Calculation
Using the formula $\text{BIC} = n \ln(\text{RSS}/n) + 5 \ln(n)$:

  $\text{bic\_before} = 9 \ln(899.50745 / 9) + 5 \ln(9) = 52.42773$
- For clean 8 points ($n=8$):

- `delta_bic` = -14.08553 - 52.42773 = -66.51303
