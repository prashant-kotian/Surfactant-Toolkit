### H32

For a spherical particle in solution at $T = 298.15\text{ K}$, translational diffusion coefficient $D = 7.5 \times 10^{-11}\text{ m}^2/\text{s}$ and solvent viscosity $\eta = 0.8903 \times 10^{-3}\text{ Pa}\cdot\text{s}$.
Using Boltzmann constant $k_B = 1.380649 \times 10^{-23}\text{ J/K}$:

1. Stokes-Einstein hydrodynamic radius $R_h$:
$$R_h = \frac{k_B T}{6\pi \eta D} = \frac{1.380649 \times 10^{-23} \times 298.15}{6\pi \times 0.8903 \times 10^{-3} \times 7.5 \times 10^{-11}} = 3.270539031705599 \times 10^{-9}\text{ m} = 3.270539031705599\text{ nm}$$

2. Perrin friction correction for a prolate ellipsoid with axial ratio $p = a/b = 1.14$:
The Perrin shape factor $F_P$ for a prolate ellipsoid ($p > 1$) is:
$$F_P = \frac{\sqrt{p^2 - 1}}{p^{2/3} \ln\left(p + \sqrt{p^2 - 1}\right)}$$
For $p = 1.14$:
$$\sqrt{1.14^2 - 1} = \sqrt{0.2996} = 0.547357$$
$$F_P = \frac{0.547357}{(1.14)^{2/3} \ln(1.14 + 0.547357)} = \frac{0.547357}{1.091522 \times 0.523164} = 1.0015326832237572$$
The true equivalent hydrodynamic radius with the Perrin correction is:
$$R_{h,\mathrm{Perrin}} = \frac{R_h}{F_P} = \frac{3.270539031705599}{1.0015326832237572} = 3.265534002523322\text{ nm}$$
