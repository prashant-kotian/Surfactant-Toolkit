# EACN of Octylbenzene

## Structure Analysis

Octylbenzene (SMILES: c1ccccc1CCCCCCCC) consists of:
- A benzene (aromatic) ring: 6 carbons
- One unbranched saturated alkyl side chain: **8 carbons** (–CH₂CH₂CH₂CH₂CH₂CH₂CH₂CH₃)
- Total molecular carbons: 14

## Applying the Rule

The problem states the group-contribution rule for alkylbenzenes:

> The aromatic ring contributes **0** to the EACN. Only the unbranched saturated side chain determines the EACN, which equals the EACN of an n-alkane with the same number of carbons as that side chain.

Therefore:

$$\text{EACN} = \text{number of carbons in the alkyl side chain} = 8$$

The 6 ring carbons do **not** add to the EACN (they contribute 0), so the total carbon count of 14 is irrelevant.

## Result

$$\boxed{\text{EACN} = 8.0}$$

**Rule applied:** Alkyl side-chain equivalence rule (aromatic ring contributes zero to EACN; EACN equals the carbon number of the n-alkyl side chain).
