# Ideal Mixed CMC – Clint's Equation

## Formula

Clint's ideal mixing rule for the mixed CMC is:

$$\frac{1}{\text{CMC}_{\text{mix}}} = \frac{\alpha_1}{\text{CMC}_1} + \frac{\alpha_2}{\text{CMC}_2}$$

where $\alpha_2 = 1 - \alpha_1$.

## Given Data

| Parameter | Value |
|-----------|-------|
| $\alpha_1$ | 0.37 |
| $\alpha_2$ | 0.63 |
| CMC₁ | 1.23 mM |
| CMC₂ | 8.76 mM |

## Calculation

**Step 1:** Compute each term in the sum:

$$\frac{\alpha_1}{\text{CMC}_1} = \frac{0.37}{1.23} = 0.30081301 \;\text{mM}^{-1}$$

$$\frac{\alpha_2}{\text{CMC}_2} = \frac{0.63}{8.76} = 0.07191781 \;\text{mM}^{-1}$$

**Step 2:** Sum:

$$\frac{1}{\text{CMC}_{\text{mix}}} = 0.30081301 + 0.07191781 = 0.37273082 \;\text{mM}^{-1}$$

**Step 3:** Invert:

$$\text{CMC}_{\text{mix}} = \frac{1}{0.37273082} = 2.6829 \;\text{mM}$$

## Result

The ideal mixed CMC is **2.6829 mM**.

# Rubingh's Regular Solution Theory – Micellar Mole Fraction

## Governing Equation

In Rubingh's regular solution theory, the micellar mole fraction $x_1$ satisfies:

$$x_1^2 \ln\!\left(\frac{\alpha_1\, C^*}{x_1\,\text{CMC}_1}\right) = (1-x_1)^2 \ln\!\left(\frac{\alpha_2\, C^*}{(1-x_1)\,\text{CMC}_2}\right)$$

This follows from equating the ratio $\ln f_1/\ln f_2 = (1-x_1)^2/x_1^2$ with the activity-coefficient expressions $f_i$ derived from the phase-separation model.

$$B = \frac{\alpha_2 C^*}{\text{CMC}_2} = \frac{0.58\times2.31}{9.80} = 0.136714$$

Solve $g(x_1)=x_1^2\ln(A/x_1)-(1-x_1)^2\ln\!\big(B/(1-x_1)\big)=0$.

## Iterative Solution (bisection / interpolation)

# Motomura's Ideal Mixed-Micelle Composition

## Theory

In Motomura's thermodynamic treatment of ideal mixed micelles, at the mixed CMC $C^*$, the chemical potential equality for each component gives:

$$x_1 = \frac{\alpha_1\, C^*}{\text{CMC}_1}, \qquad 1-x_1 = \frac{\alpha_2\, C^*}{\text{CMC}_2}$$

Combining with Clint's ideal mixing relation $C^* = \left(\frac{\alpha_1}{\text{CMC}_1}+\frac{\alpha_2}{\text{CMC}_2}\right)^{-1}$, the ideal micellar mole fraction is:

$$x_1 = \frac{\alpha_1/\text{CMC}_1}{\alpha_1/\text{CMC}_1 + \alpha_2/\text{CMC}_2}$$

## Calculation

Given: $\alpha_1 = 0.63$, $\alpha_2 = 0.37$, CMC₁ = 0.87 mM, CMC₂ = 6.54 mM

**Step 1:** Compute each ratio:

$$\frac{\alpha_1}{\text{CMC}_1} = \frac{0.63}{0.87} = 0.724138 \;\text{mM}^{-1}$$

$$\frac{\alpha_2}{\text{CMC}_2} = \frac{0.37}{6.54} = 0.056575 \;\text{mM}^{-1}$$

**Step 2:** Sum:

$$0.724138 + 0.056575 = 0.780713 \;\text{mM}^{-1}$$

**Step 3:** Micellar mole fraction:

$$x_1 = \frac{0.724138}{0.780713} = 0.92753$$

## Result

$$\boxed{x_1 = 0.9275}$$

# Asymmetric (Two-Parameter) Margules Activity Coefficients

## Model Equations

The asymmetric Margules model for excess Gibbs energy:
$$\frac{g^E}{RT} = x_1 x_2\,(w_{21}\,x_1 + w_{12}\,x_2)$$

yields the activity coefficients:

$$\ln f_1 = x_2^2\bigl[w_{12} + 2(w_{21}-w_{12})\,x_1\bigr]$$
$$\ln f_2 = x_1^2\bigl[w_{21} + 2(w_{12}-w_{21})\,x_2\bigr]$$

## Given Data
- $x_1 = 0.58$, $x_2 = 0.42$
- $w_{12} = 4.21$, $w_{21} = 1.87$

## Calculation of $f_1$

$$\ln f_1 = (0.42)^2\bigl[4.21 + 2(1.87 - 4.21)(0.58)\bigr]$$
$$= 0.1764\bigl[4.21 + 2(-2.34)(0.58)\bigr]$$
$$= 0.1764\bigl[4.21 - 2.7144\bigr]$$
$$= 0.1764 \times 1.4956 = 0.26382$$

$$f_1 = e^{0.26382} = 1.3019$$

## Calculation of $f_2$

$$\ln f_2 = (0.58)^2\bigl[1.87 + 2(4.21 - 1.87)(0.42)\bigr]$$
$$= 0.3364\bigl[1.87 + 2(2.34)(0.42)\bigr]$$
$$= 0.3364\bigl[1.87 + 1.9656\bigr]$$
$$= 0.3364 \times 3.8356 = 1.29030$$

$$f_2 = e^{1.29030} = 3.6339$$

## Result

$$\boxed{f_1 = 1.3019,\quad f_2 = 3.6339}$$

# Excess Gibbs Free Energy of Mixing (Chained Calculation)

## Step 1: Activity Coefficients (from Asymmetric Margules Model)

Using the same parameters as Q05 ($x_1=0.58$, $w_{12}=4.21$, $w_{21}=1.87$):

$$\ln f_1 = x_2^2[w_{12}+2(w_{21}-w_{12})x_1] = (0.42)^2[4.21-2.7144] = 0.26382$$

$$\ln f_2 = x_1^2[w_{21}+2(w_{12}-w_{21})x_2] = (0.58)^2[1.87+1.9656] = 1.29030$$

## Step 2: Excess Gibbs Free Energy

The excess Gibbs free energy of mixing per mole of micelle is:

$$g^E = RT\bigl[x_1 \ln f_1 + x_2 \ln f_2\bigr]$$

(Equivalently, from the Margules model directly: $g^E/RT = x_1 x_2(w_{21}x_1 + w_{12}x_2)$)

**Compute the dimensionless excess term:**

$$x_1 \ln f_1 + x_2 \ln f_2 = 0.58(0.26382) + 0.42(1.29030)$$
$$= 0.153016 + 0.541926 = 0.694942$$

*Verification via Margules:* $0.58\times0.42\times(1.87\times0.58+4.21\times0.42) = 0.2436\times2.8528 = 0.694942$ ✓

**Compute RT:**

$$RT = 8.314 \times 308.15 = 2561.96 \;\text{J/mol}$$

**Final computation:**

$$g^E = 2561.96 \times 0.694942 = 1780.41 \;\text{J/mol} = 1.7804 \;\text{kJ/mol}$$

## Result

$$\boxed{g^E = 1.7804 \;\text{kJ/mol}}$$

Q07
# Rodenas' Method – Micellar Mole Fraction from CMC Slope

## Derivation of the Rodenas Equation

Starting from the phase-separation model at the mixed CMC:
$$\alpha_1 C^* = x_1 f_1 \text{CMC}_1, \qquad (1-\alpha_1)C^* = (1-x_1)f_2\text{CMC}_2$$

Differentiating both (with respect to $\alpha_1$), multiplying the first by $x_1$ and the second by $(1-x_1)$, then adding, the activity-coefficient derivative terms cancel via the **Gibbs–Duhem equation** ($x_1\,d\ln f_1 + x_2\,d\ln f_2 = 0$), yielding:

$$\frac{x_1}{\alpha_1} - \frac{1-x_1}{1-\alpha_1} + \frac{d\ln C^*}{d\alpha_1} = 0$$

Solving for $x_1$:

$$\boxed{x_1 = \alpha_1 - \alpha_1(1-\alpha_1)\,\frac{d\ln C^*}{d\alpha_1}}$$

This result is **exact and model-independent** (no assumption of ideality required).

## Numerical Calculation

Given: $\alpha_1 = 0.55$, $\dfrac{d\ln C^*}{d\alpha_1} = -0.83$

$$x_1 = 0.55 - (0.55)(0.45)(-0.83)$$

$$= 0.55 - (0.2475)(-0.83)$$

$$= 0.55 + 0.205425$$

$$= 0.755425$$

## Result

$$\boxed{x_1 = 0.7554}$$

# Maeda's Theory – Free Energy of Mixed Micelle Formation

## Maeda's Formula

The standard free energy of mixed micelle formation per mole of micelle is:

$$\Delta G_M = RT\bigl[x_1\ln(x_1 f_1\,\text{CMC}_1) + x_2\ln(x_2 f_2\,\text{CMC}_2)\bigr]$$

Using the regular solution model ($\ln f_1 = \beta(1-x_1)^2$, $\ln f_2 = \beta x_1^2$), the excess terms combine:

$$x_1\ln f_1 + x_2\ln f_2 = \beta x_1(1-x_1)^2 + \beta x_1^2(1-x_1) = \beta x_1(1-x_1)$$

So the working formula becomes:

$$\Delta G_M = RT\bigl[x_1\ln(x_1\,\text{CMC}_1) + x_2\ln(x_2\,\text{CMC}_2) + \beta\,x_1 x_2\bigr]$$

## Numerical Evaluation

**Given:** $x_1=0.61$, $x_2=0.39$, $\beta=-3.4$, CMC₁ = 1.5×10⁻³ M, CMC₂ = 4.7×10⁻³ M, $T=298.15$ K

**Term 1:** $x_1\ln(x_1\,\text{CMC}_1) = 0.61\times\ln(9.15\times10^{-4}) = 0.61\times(-6.9966) = -4.2679$

**Term 2:** $x_2\ln(x_2\,\text{CMC}_2) = 0.39\times\ln(1.833\times10^{-3}) = 0.39\times(-6.3018) = -2.4577$

**Term 3:** $\beta\,x_1 x_2 = -3.4\times0.61\times0.39 = -0.8089$

**Sum of bracket:**
$$-4.2679 + (-2.4577) + (-0.8089) = -7.5345$$

**Multiply by RT:**
$$RT = 8.314\times298.15 = 2478.82\;\text{J/mol}$$

$$\Delta G_M = 2478.82\times(-7.5345) = -18676.5\;\text{J/mol}$$

## Result

$$\boxed{\Delta G_M = -18.677\;\text{kJ/mol}}$$

# Rosen's Regular Solution Theory – Monolayer Composition

## Theory

Rosen's theory for the mixed monolayer at the air–water interface is formally identical to Rubingh's micellar theory, but uses concentrations at a **fixed reference surface tension** $\sigma$ instead of CMCs:

$$\alpha_1\, c_{\text{mix},\sigma} = x_1\, f_1^\sigma\, c_{1,\sigma}$$
$$\alpha_2\, c_{\text{mix},\sigma} = (1-x_1)\, f_2^\sigma\, c_{2,\sigma}$$

With regular-solution activity coefficients $f_1^\sigma = e^{\beta^\sigma(1-x_1)^2}$, $f_2^\sigma = e^{\beta^\sigma x_1^2}$, eliminating $\beta^\sigma$ yields the same transcendental equation:

$$x_1^2 \ln\!\left(\frac{\alpha_1\, c_{\text{mix},\sigma}}{x_1\, c_{1,\sigma}}\right) = (1-x_1)^2 \ln\!\left(\frac{\alpha_2\, c_{\text{mix},\sigma}}{(1-x_1)\, c_{2,\sigma}}\right)$$
