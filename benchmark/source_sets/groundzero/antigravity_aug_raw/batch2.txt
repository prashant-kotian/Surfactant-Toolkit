**Activity Coefficient Analysis & Asymmetry:**
Examining the measured activity coefficients across the composition series:
- $x_1 = 0.305 \implies f_1 = 0.394, f_2 = 0.650$
- $x_1 = 0.415 \implies f_1 = 0.630, f_2 = 0.500$
- $x_1 = 0.483 \implies f_1 = 0.769, f_2 = 0.426$
- $x_1 = 0.626 \implies f_1 = 0.970, f_2 = 0.322$
- $x_1 = 0.808 \implies f_1 = 1.028, f_2 = 0.286$

Under Rubingh's regular solution theory (RST), a single symmetric interaction parameter $\beta$ requires $\ln f_1 = \beta (1 - x_1)^2$ and $\ln f_2 = \beta x_1^2$. As $x_1 \to 1$, $f_1 \to 1$, while $f_2 \to \exp(\beta)$. However, the experimental data shows marked asymmetry: $f_1$ exceeds unity ($f_1 = 1.028$ at $x_1 = 0.808$) while $f_2$ remains strongly depressed ($f_2 \approx 0.286$), which a single symmetric parameter cannot reproduce.

**Asymmetric Margules (EOMMM) Formulation:**
Using the two-parameter Margules model:
$$\ln f_1 = (1 - x_1)^2 [w_{12} + 2(w_{21} - w_{12}) x_1]$$
$$\ln f_2 = x_1^2 [w_{21} + 2(w_{12} - w_{21}) (1 - x_1)]$$

Regressing $w_{12}$ and $w_{21}$ across the 5 interior composition points yields:
$$w_{12} \approx -3.566\text{ }RT,\quad w_{21} \approx -0.889\text{ }RT$$

**Prediction at $x_1 = 0.90$:**
Substituting $x_1 = 0.90$ ($x_2 = 0.10$):
$$\ln f_1 = (0.10)^2 [-3.566 + 2(-0.889 + 3.566)(0.90)] = 0.0125 \implies f_1 \approx 1.0126$$
$$\ln f_2 = (0.90)^2 [-0.889 + 2(-3.566 + 0.889)(0.10)] = -1.1536 \implies f_2 \approx 0.3155$$
