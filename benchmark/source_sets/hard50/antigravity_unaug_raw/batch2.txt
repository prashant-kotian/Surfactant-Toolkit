   For pure components $C_1^* = 8.0\text{ mM}$ and $C_2^* = 15.0\text{ mM}$, the mixed micelle composition $x_1$ satisfies the implicit mass-balance relation:
   $$F(x_1) = x_1^2 \ln\left(\frac{\alpha_1 \text{CMC}_{\text{mix}}}{x_1 C_1^*}\right) - (1 - x_1)^2 \ln\left(\frac{(1 - \alpha_1) \text{CMC}_{\text{mix}}}{(1 - x_1) C_2^*}\right) = 0$$
   A physical solution must satisfy $0 < x_1 < 1$. Once $x_1$ is found, the interaction parameter $\beta$ is computed via:
   $$\beta = \frac{\ln\left(\frac{\alpha_1 \text{CMC}_{\text{mix}}}{x_1 C_1^*}\right)}{(1 - x_1)^2} = \frac{\ln\left(\frac{(1 - \alpha_1)\text{CMC}_{\text{mix}}}{(1 - x_1) C_2^*}\right)}{x_1^2}$$

2. **Point-by-Point Root Evaluation**:

     $\alpha_1 \text{CMC}_{\text{mix}} / C_1^* = 0.90 / 8.0 = 0.1125$, $(1 - \alpha_1) \text{CMC}_{\text{mix}} / C_2^* = 8.10 / 15.0 = 0.540$.

   - **Point 3** ($\alpha_1 = 0.50, \text{CMC}_{\text{mix}} = 15.0\text{ mM}$):

     $\alpha_1 \text{CMC}_{\text{mix}} = 11.2\text{ mM} > C_1^* = 8.0\text{ mM}$. Because $\alpha_1 \text{CMC}_{\text{mix}} / C_1^* = 1.40 > 1$, $F(x_1) > 0$ strictly across the entire open interval $(0, 1)$. No physical root exists.
