### Question H21

#### Principles and Calculations
1. **Prefactor in the Gibbs Adsorption Equation**:
   The Gibbs adsorption isotherm relates the change in interfacial tension $d\gamma$ to the chemical potential of adsorbing species:
   $$d\gamma = -\sum_i \Gamma_i d\mu_i$$
   For a 1:1 ionic surfactant ($M^+ X^-$) in water in the **complete absence of added electrolyte**, both the surfactant cation and the counterion must simultaneously adsorb at the interface to maintain local electroneutrality ($\Gamma_+ = \Gamma_- = \Gamma$). The chemical potential is given by:
   $$\mu = \mu_+ + \mu_- = \mu^0 + RT \ln a_+ + RT \ln a_- \approx \mu^0 + 2RT \ln C$$
   Therefore, $d\mu = 2RT d(\ln C)$, giving a prefactor of **$n = 2$**:
   $$\Gamma_{\max} = -\frac{1}{2RT} \frac{d\gamma}{d\ln C}$$

2. **Maximum Surface Excess ($\Gamma_{\max}$)**:
   Given:
   - $d\gamma/d(\ln C) = -15.2\text{ mN/m} = -1.52 \times 10^{-2}\text{ N/m}$
   - $T = 298.15\text{ K}$, $R = 8.314462618\text{ J/(mol}\cdot\text{K)}$
   - $2RT = 2 \times 8.314462618 \times 298.15 = 4957.914\text{ J/mol}$
   $$\Gamma_{\max} = \frac{1.52 \times 10^{-2}\text{ N/m}}{4957.914\text{ J/mol}} = 3.065805 \times 10^{-6}\text{ mol/m}^2$$

3. **Minimum Area per Molecule ($A_{\min}$)**:
   Using Avogadro's constant $N_A = 6.02214076 \times 10^{23}\text{ mol}^{-1}$:
   $$A_{\min} = \frac{1}{N_A \Gamma_{\max}} = \frac{1}{(6.02214076 \times 10^{23}\text{ mol}^{-1})(3.065805 \times 10^{-6}\text{ mol/m}^2)} = 5.416322 \times 10^{-19}\text{ m}^2 = 54.1632\text{ \AA}^2$$

4. **Discrepancy vs. Literature Value**:
   Given literature $A_{\min} = 44.70\text{ \AA}^2$:
   $$\text{Discrepancy} = \frac{|A_{\min,\text{slope}} - A_{\min,\text{lit}}|}{A_{\min,\text{lit}}} \times 100 = \frac{|54.1632 - 44.70|}{44.70} \times 100 = 21.17\%$$

### Question H22

#### Principles and Calculations
1. **Ideal Mixed CMC (Clint Equation)**:
   For an ideal binary surfactant mixture, the mixed CMC ($C_{\text{id}}$ or $C_{\text{lint}}$) is given by:
   $$\frac{1}{C_{\text{lint}}} = \frac{\alpha_1}{C_1^*} + \frac{1 - \alpha_1}{C_2^*}$$
   With $C_1^* = 1.8\text{ mM}$, $C_2^* = 15.6\text{ mM}$, and $\alpha_1 = 0.30$:
   $$\frac{1}{C_{\text{lint}}} = \frac{0.30}{1.8} + \frac{0.70}{15.6} = 0.166667 + 0.044872 = 0.211538\text{ mM}^{-1}$$
   $$C_{\text{lint}} = \frac{1}{0.211538} = 4.7273\text{ mM}$$

2. **Percent Deviation of Measured CMC**:
   With $C_{\text{meas}} = 4.05\text{ mM}$:
   $$\text{Deviation (\%)} = \frac{C_{\text{lint}} - C_{\text{meas}}}{C_{\text{meas}}} \times 100 = \frac{4.7273 - 4.05}{4.05} \times 100 = +16.72\%$$
   The positive sign reflects non-ideal synergistic mixing ($C_{\text{meas}} < C_{\text{lint}}$).

3. **Rubingh Micellar Mole Fraction ($x_1$)**:
   The composition $x_1$ satisfies Rubingh's transcendental mass balance:
   $$x_1^2 \ln\left(\frac{\alpha_1 C_{\text{mix}}}{x_1 C_1^*}\right) = (1 - x_1)^2 \ln\left(\frac{(1 - \alpha_1) C_{\text{mix}}}{(1 - x_1) C_2^*}\right)$$
   $$\frac{\alpha_1 C_{\text{mix}}}{C_1^*} = \frac{0.30 \times 4.05}{1.8} = 0.675,\quad \frac{(1 - \alpha_1) C_{\text{mix}}}{C_2^*} = \frac{0.70 \times 4.05}{15.6} = 0.181731$$
   Solving for $x_1 \in (0, 1)$ numerically gives:
   $$x_1 = 0.7203$$

4. **Rubingh Interaction Parameter ($\beta$)**:
   $$\beta = \frac{\ln\left(\frac{\alpha_1 C_{\text{mix}}}{x_1 C_1^*}\right)}{(1 - x_1)^2} = \frac{\ln\left(\frac{0.675}{0.7203}\right)}{(1 - 0.7203)^2} = \frac{\ln(0.93708)}{0.078219} = -0.8309$$

### Question H23

#### Principles and Calculations
1. **Endpoint van 't Hoff Enthalpy of Micellization ($\Delta H_{\text{mic}}$)**:
   From the pseudo-phase separation model, the standard Gibbs free energy of micellization is $\Delta G_{\text{mic}} = RT \ln X_{\text{CMC}}$, leading via the Gibbs-Helmholtz relation to the van 't Hoff equation:
   $$\Delta H_{\text{mic}} = R \frac{d\ln(\text{CMC})}{d(1/T)} = R \frac{\ln(\text{CMC}_2 / \text{CMC}_1)}{1/T_2 - 1/T_1}$$
   - Row 1: $T_1 = 10\text{ }^\circ\text{C} = 283.15\text{ K}$, $\text{CMC}_1 = 9.93\text{ mM}$
   - Row 8: $T_2 = 45\text{ }^\circ\text{C} = 318.15\text{ K}$, $\text{CMC}_2 = 11.47\text{ mM}$
   $$\frac{1}{T_2} - \frac{1}{T_1} = \frac{1}{318.15} - \frac{1}{283.15} = 0.00314317 - 0.00353170 = -0.000388525\text{ K}^{-1}$$
   $$\ln\left(\frac{\text{CMC}_2}{\text{CMC}_1}\right) = \ln\left(\frac{11.47}{9.93}\right) = +0.144161$$
   $$\Delta H_{\text{mic}} = (8.314462618\text{ J/(mol}\cdot\text{K)}) \times \frac{0.144161}{-0.000388525\text{ K}^{-1}} \times 10^{-3}\text{ kJ/J} = -3.085\text{ kJ/mol}$$

### Question H24

#### Principles and Calculations
1. **Stokes-Einstein Hydrodynamic Radius ($R_h$)**:
   Given $T = 298.15\text{ K}$, $\eta = 0.8903\text{ mPa}\cdot\text{s} = 8.903 \times 10^{-4}\text{ kg/(m}\cdot\text{s)}$, and $D = 1.1 \times 10^{-6}\text{ cm}^2/\text{s} = 1.1 \times 10^{-10}\text{ m}^2/\text{s}$:
   $$R_h = \frac{k_B T}{6\pi \eta D} = \frac{(1.380649 \times 10^{-23}\text{ J/K})(298.15\text{ K})}{6\pi (8.903 \times 10^{-4}\text{ Pa}\cdot\text{s})(1.1 \times 10^{-10}\text{ m}^2/\text{s})} = 2.2299 \times 10^{-9}\text{ m} = 2.2299\text{ nm}$$

2. **Aggregation Number ($N_{\text{agg}}$)**:
   Assuming a spherical micelle whose dry volume is approximated by the sphere of radius $R_h$:
   $$V = \frac{4}{3}\pi R_h^3 = \frac{4}{3}\pi (2.229913 \times 10^{-7}\text{ cm})^3 = 4.64464 \times 10^{-20}\text{ cm}^3$$
   Using $\bar{v} = 0.90\text{ mL/g} = 0.90\text{ cm}^3/\text{g}$:
   $$m_{\text{micelle}} = \frac{V}{\bar{v}} = \frac{4.64464 \times 10^{-20}}{0.90} = 5.16071 \times 10^{-20}\text{ g}$$
   $$M_{\text{micelle}} = m_{\text{micelle}} N_A = (5.16071 \times 10^{-20})(6.022141 \times 10^{23}) = 31078.5\text{ g/mol}$$
   $$N_{\text{agg}} = \frac{M_{\text{micelle}}}{M_0} = \frac{31078.5}{448.6} = 69.28 \approx 69\text{ molecules}$$

3. **Systematic Bias**:
   DLS measures the hydrodynamic radius $R_h$, which includes the hydrated headgroup shell, bound counterions, and drag-entrained water molecules. Because $R_h > R_{\text{dry}}$, using $R_h$ systematically **overestimates** the dry micellar core volume and true aggregation number.

### Question H25

#### Principles and Calculations
1. **Ionic Strength ($I$)**:
   $$I = \frac{1}{2} \sum_{i} c_i z_i^2$$
   - $\text{Na}^+$ ($c = 0.060\text{ M}, z = 1$): $0.060 \times 1^2 = 0.060\text{ M}$
   - $\text{Ca}^{2+}$ ($c = 0.015\text{ M}, z = 2$): $0.015 \times 2^2 = 0.060\text{ M}$
   - $\text{Cl}^-$ ($c = 0.090\text{ M}, z = -1$): $0.090 \times (-1)^2 = 0.090\text{ M}$
   $$I = \frac{1}{2} (0.060 + 0.060 + 0.090) = 0.105\text{ M} = 105\text{ mM}$$

2. **Debye Length ($\lambda_D$)**:
   $$\lambda_D = \frac{0.304}{\sqrt{I\text{ in mol/L}}}\text{ nm} = \frac{0.304}{\sqrt{0.105}}\text{ nm} = \frac{0.304}{0.324037}\text{ nm} = 0.9382\text{ nm}$$

3. **Dimensionless Electrokinetic Product ($\kappa a$)**:
   With $a = 2.5\text{ nm}$:
   $$\kappa a = \frac{a}{\lambda_D} = \frac{2.5}{0.938164} = 2.665$$

4. **Henry Function $F(\kappa a)$ Evaluation**:
   At $\kappa a = 2.665$, the system resides in the intermediate electrokinetic transition between the Hückel limit ($f = 1.0$) and Smoluchowski limit ($f = 1.5$). Using Ohshima's closed-form analytical expression for dielectric spheres (which matches full numerical electrokinetic theory within $<1\%$ across all $\kappa a$):
   $$f(\kappa a) = 1 + \frac{1}{2}\left[1 + \frac{2.5}{\kappa a(1 + 2e^{-\kappa a})}\right]^{-3}$$
   At $\kappa a = 2.66478$:
   $$2.66478 \times (1 + 2e^{-2.66478}) = 2.66478 \times 1.13923 = 3.0358$$
   $$1 + \frac{2.5}{3.0358} = 1.8235 \implies (1.8235)^{-3} = 0.1649$$
   $$F(\kappa a) = 1 + 0.5 \times 0.1649 = 1.083$$
