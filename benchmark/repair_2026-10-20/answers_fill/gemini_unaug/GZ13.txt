from scipy.stats import linregress
# Use indices 2, 3, 4
x = ln_c[2:5]
y = gamma[2:5]
slope, intercept, r_value, p_value, std_err = linregress(x, y)
print(f"Pre-CMC Line: gamma = {slope} * ln_c + {intercept}")

# True plateau is likely 36.224
# Find intersection
ln_cmc = (36.224 - intercept) / slope
cmc = np.exp(ln_cmc)
print(f"CMC = {cmc} mM")

# What if plateau is 32.348?
ln_cmc_min = (32.348 - intercept) / slope
cmc_min = np.exp(ln_cmc_min)
print(f"CMC (using minimum) = {cmc_min} mM")

# Thermodynamic properties
T = 296.35 # K
R = 8.314 # J/mol*K
# Gamma_max = - slope / (n * R * T)
# For DTAB without added salt, n = 2
gamma_max = - slope / (2 * R * T) * 1000 # mN/m = 1e-3 J/m2, so slope is in mN/m. 
# wait: slope is d(gamma)/d(ln c). gamma is mJ/m^2. 
# Gamma_max = - (1e-3 * slope) / (2 * 8.314 * 296.35)  in mol / m^2
gamma_max_mol_per_m2 = - (slope * 1e-3) / (2 * 8.314 * 296.35)
print(f"Gamma_max = {gamma_max_mol_per_m2} mol/m2")

N_A = 6.022e23
a_min = 1e18 / (gamma_max_mol_per_m2 * N_A) # nm^2
print(f"a_min = {a_min} nm^2")

# Delta G mic = n * R * T * ln(x_cmc)
# x_cmc = cmc / 55500 (mol fraction)
x_cmc = cmc / 55500
x_cmc_min = cmc_min / 55500
dg_mic = 2 * R * T * np.log(x_cmc) / 1000 # kJ/mol
print(f"delta_g_mic = {dg_mic} kJ/mol")

dg_mic_min = 2 * R * T * np.log(x_cmc_min) / 1000 # kJ/mol
print(f"delta_g_mic (min) = {dg_mic_min} kJ/mol")

**Analysis of GZ-13 (Nonionic Surfactant)**
The given SMILES string represents a cetyl alcohol ethoxylate (Ceteth-10), consisting of a hexadecyl (C16) hydrophobic tail and a polyoxyethylene hydrophilic head ending in a hydroxyl group.

* **Ethylene-oxide units**: Splitting the SMILES by the oxygen atoms reveals 10 `-CH2-CH2-O-` (or `CCO`) repeat units.
* **Molecular Weight**: The molecular formula is C36H74O11. Total molecular weight is $36(12.011) + 74(1.008) + 11(15.999) = 682.98 \text{ g/mol}$.
* **HLB (Griffin's method)**: The hydrophobe is the cetyl chain (C16H33–) with a mass of $225.44 \text{ g/mol}$. The hydrophilic portion is the remainder of the molecule (the polyether chain and terminal hydroxyl), which has a mass of $682.98 - 225.44 = 457.54 \text{ g/mol}$.
$\text{HLB} = 20 \times \frac{457.54}{682.98} = 13.40$
