Executive assessment
Paper 1 has a potentially useful methods question and the record shows thoughtful correction of  
earlier modeling and editorial errors. The current submission is not ready for submission or for relying on  
its headline precision claims. The strongest defensible conclusion today is narrower: a particular model  
can produce synthetic signals from which τ₂ may be estimated in selected parameter and bandwidth  
regimes, conditional on externally known reservoir capacity and idealized assumptions.
The  main  blockers  are  a  mismatch  between  the  manuscript’s  quoted  precision  and  the 
current/research recoverability results; incomplete or absent experimental validation; unresolved model  
conservation  and  adapter  defects;  uncited  placeholders  and  not  directly  checked  references;  and  an 
inaccessible private SurfactantKit repository whose contents cannot be audited from this environment.
1. Critical: headline precision is not supported by the current evidence
The submission advertises 0.2–0.3% statistical precision and 0.23% relative standard error. In  
contrast,  retained  research  artifacts  report  very  poor  recovery  for  many  settings:  
recoverability_results.json has relative SEs ranging from about 0.97 to over 1,300 in its documented  
parameterizations; recoverability_v2.json reports large two-parameter-fit uncertainty at 0.05 mN/m noise;  
FINDINGS.md describes 0.04–0.23 relative SE in a different bandwidth study, i.e. 4–23%, not 0.04–
0.23%. Those  are  not  interchangeable  metrics  or  evidently  the  same  experiment.  The  0.23%  figure 
appears tied to a separate, most favorable synthetic setup and selected top-of-band operating point.
Fix:  make  one  canonical,  reproducible  analysis  configuration  for  every  published  number. 
Recompute uncertainty from stated noise, replicate count, sampled frequencies, nuisance parameters, and  
the exact observable. Report absolute units and relative SE consistently (e.g. 0.23% versus 0.23). Include  
confidence intervals/coverage from repeated synthetic draws and a profile likelihood or bootstrap. If  
results do not replicate, remove the precision headline and present sensitivity bounds. Label the ω=6.28  
rad/s result as best-case and state that systematic uncertainty in nE  and capacity dominates.

2. Critical: no empirical validation of the proposed inversion
The manuscript itself states that no measured C₁₂E₈ LAOD dataset was inverted and τ₂=4 s is a  
literature benchmark. All quantitative results are generated by the same forward model used to claim  
recoverability. This demonstrates internal numerical behavior, not that measured interfacial dynamics  
follow the model or that τ₂ is experimentally identifiable.
Fix:  reframe  as  a  computational  feasibility  study  until  an  experiment  or  independent  data 
reanalysis is completed. Minimum validation: collect or obtain a C₁₂E₈ frequency sweep above CMC,  
estimate  τ₂  using  the  proposed  protocol,  and  compare  blind  against  an  independent  relaxation 
measurement with uncertainty. Validate residuals and model adequacy, not merely parameter recovery on  
synthetic data. Avoid statements that the method replaces dedicated equipment before this succeeds.
3. Critical: mass-conservation claim and implementation do not agree
model.py says total surfactant is conserved by construction, but OscillationResult.mass_error is  
always returned as NaN, and the simulation uses a fixed far-end Dirichlet concentration that can act as a  
source/sink. More fundamentally, Γ is diluted through −Γ dlnA/dt while the reported bulk inventory is  
integrated on a fixed planar domain; consistent accounting of changing interfacial area and flux per actual  
area is not demonstrated. The code’s total_surfactant helper is defined but not used to calculate an error.  
The “conserved species” exchange term can conserve local monomer plus micellar concentration, but that  
alone does not prove global system conservation.
Fix: define the control volume and whether the interface area is normalized. Derive a discrete  
mass balance including area(t)Γ, finite-volume bulk inventory, micellar inventory, and far-boundary flux.  
Either use a closed/no-flux finite domain for a conservation benchmark or explicitly report boundary  
exchange for the semi-infinite approximation. Compute and return mass_error on every run; fail/flag  
when it exceeds tolerance. Add oscillatory mass-balance and grid/domain convergence checks before  
retaining “mass-conserving” language.

4. Critical: system parameter adapter is incomplete and can fail at runtime
systems.py  SurfactantSystem.to_model  passes  K=None.  ModelParams.theta0,  gamma_s_eq, 
isotherm, and dgamma_dcs require numeric K, so this object is not runnable without an undocumented  
later mutation. K_MISSING indicates SDS and CTAB also lack fitted equilibrium constants. The shown  
forward model uses Langmuir, although the system table carries Frumkin settings.
Fix: make the adapter require a validated K or fitted isotherm object and raise a clear error if  
absent. Implement the claimed Frumkin EOS in the forward model or explicitly reject those systems.  
Remove/disable system rows that cannot be instantiated. Add provenance and unit checks for every  
parameter. Do not use CTAB/SDS predictions as validated system results until isotherms and capacities  
are independently anchored.
5. High: capacity closure is presented too confidently near the CMC
systems.py documents C_m= nE (m−1) as an approximation and notes it overestimates capacity  
close to the CMC, while the paper discusses an optimum at 1.5× CMC and an inversion window starting  
at 1.2× CMC. The reported useful window therefore overlaps the regime where the current capacity  
closure is acknowledged as unreliable. Capacity inferred from CMC and aggregation number is not  
universal  without  specifying  equilibrium  model,  monomer  activity,  micelle  distribution,  and 
concentration convention.
Fix:  derive  C_m  from  the  selected  thermodynamic/micellization  model  and  propagate  its 
uncertainty. Compare the current closure with measured micellization/isotherm data over concentration.  
Either  exclude  the  near-CMC  region  or  show  that  the  inversion  window  persists  under  a  validated 
capacity  model  and  plausible  uncertainty.  Make  clear  that  “known  capacity”  is  an  additional 
measured/model-derived input, not merely known nE .
6. High: recoverability uncertainty method needs auditing
study_recoverability_v3.py computes covariance from the local least-squares Jacobian, floors  
residual variance at 1.0, and divides the log-parameter standard error by the absolute fitted log(τ₂). This is  
not generally the relative standard error of τ₂: uncertainty on log τ₂ maps approximately to relative  

5
uncertainty on τ₂, so division by |log τ₂| is mathematically inappropriate and makes results unit/scale  
dependent. The maps use a single seeded synthetic-noise realization per cell.
Fix:  calculate  SE(log  τ₂)  directly  as  approximate  relative  SE  for  small  errors,  or  transform 
confidence limits from log space to τ₂ space; never divide by |log τ₂|. Use a covariance derived from stated 
measurement covariance, then run repeated noise realizations and evaluate interval coverage. Include  
optimizer convergence, bounds, residual diagnostics, and identifiability conditioning. Rebuild all maps  
and manuscript numbers.
7. High: manuscript contains unresolved citation placeholders
PAPER1_SUBMISSION.md contains explicit [CIT: …] placeholders, including the instrument  
source, and “to be sourced” statements. The editorial record says references 4, 5, and 7 were not read  
directly. The PAT-1M acquisition rate, instrument bandwidth, and drop stability claims are operationally  
central,  yet  several  are  not  independently  verified  in  the  accessible  materials.  Reference  5  is 
bibliographically incomplete.
Fix: replace every placeholder; verify each source against the original paper or manufacturer  
documentation;  add  complete  bibliographic  metadata  and  DOI;  create  a  claim-to-source  table.  For 
manufacturer  specifications,  cite  a  manual/datasheet  and  identify  model/version.  Mark  unconfirmed 
claims as hypotheses or remove them. Re-render and inspect the final pages; the record documents  
previous editorial appendix and “Reference flags” leakage.
8. High: theoretical 45° ceiling needs exact definition and scope
The manuscript calls the 45° loss-angle bound categorical and model-free for diffusion-only  
monolayers. It must define the sign convention, phase extraction, forcing/response pair, harmonic used,  
and assumptions (linear response, diffusion-only transport, passive interface, constitutive equation). In  
large-amplitude  response,  harmonic-specific  phase  and  nonlinear  harmonics  complicate  direct 
interpretation. A threshold observed under a specific model should not be described as universal without a 
derivation and counterexample search.

6
Fix: provide a derivation with assumptions and prove the phase bound for the precise measured  
quantity; separately test nonlinear diffusion-only simulations and instrumental phase delays. Use “within  
the stated model and measurement definition” unless a broader theorem is established.
9. High: novelty and external comparison should be narrowed
The  research notes  identify prior  LAE work by Czakaj et al. (2021) measuring I₂/I₁ versus  
concentration. The manuscript recognizes this, but broader claims require a systematic literature search.  
The defensible novelty may be inversion of τ₂ / phase-frequency analysis, if supported, not first use of  
harmonic analysis in LAOD.
Fix: cite and describe the Czakaj study accurately, search for oscillatory surface-rheology phase  
and micellar-relaxation inversion, and state a narrow novelty claim. Keep LAE as context, not validation  
of the C₁₂E₈ model.
10. Companion SurfactantKit repository was not auditable here
GitHub metadata identifies prashant-kotian/surfactantkit as private. A root listing was returned,  
but subsequent API access failed in this session, and no local SurfactantKit checkout is available at the  
provided path. Therefore I could not inspect its implementation, tests, or shared model interfaces. The  
simulation README promises integration with SurfactantKit, but the Paper 1 research code inspected  
appears standalone and does not call the toolkit.
Fix:  provide  a  local  checkout  or  repository  access  for  a  code-level  review.  Document  the 
integration boundary and version/commit used. If Paper 1 does not use SurfactantKit, remove claims that  
calculations are integrated with or validated by it. Ensure the public snapshot contains the exact code and  
data used for the manuscript.
11. Medium: reproducibility and artifact provenance are incomplete
FINDINGS.md gives a branch name, but this checkout’s git status/history could not be read  
because Git rejected the repository as dubious ownership. The central LAOD study lacks an obvious  
frozen environment lockfile, command manifest, and generated-input provenance in the inspected files.  
Some JSON result files appear to reflect older runs and contradict newer FINDINGS text.

7
Fix: provide a tagged analysis snapshot with dependency lockfile, exact commands, machine-
readable configs, input checksums, and scripts that regenerate every table and figure. Keep superseded  
runs labeled and out of the manuscript path. Record a commit SHA only after verifying the tag.
12. Priority plan
P0 — Fix uncertainty calculation and regenerate every headline number; reconcile the paper with  
all JSON artifacts. Disable or correct non-runnable system adapters and implement measurable mass  
accounting.
P1 — Decide claim level: computational methods proposal now, or experimentally validated  
method after an independent C₁₂E₈ sweep. Validate capacity across the stated concentration window.
P2 — Complete source verification, replace placeholders, narrow novelty, and document the 45°  
result’s assumptions and proof.
P3 — Freeze reproducible code/data/configuration, audit toolkit integration, then rebuild and  
visually inspect the final manuscript PDF, especially its last pages.
Overall recommendation
Major revision before submission. The central idea is worth testing, but the strongest current  
evidence supports a model-internal feasibility result, not a validated measurement method at sub-percent  
precision. Correcting uncertainty reporting and proving the mass accounting are the highest priorities  
because they can change the paper’s quantitative conclusion.
